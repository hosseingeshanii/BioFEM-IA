Partitioned variant of RunCudaSubdivGeomKernel for the DMPlex+CUDA path: operates on a per-rank local cell subset (from a DMPlexPatchLayout) instead of the whole, undistributed ibm->n_elmt/ire/val/patch arrays.

Parameters
femFE struct (fem->ibm and fem->act_data must be initialised, coordinates already SF-exchanged).
nLocalCellsNumber of cells owned by this rank's layout.
localOrigCelllocalOrigCell[lc] = original/global element index for local cell lc (from DMPlexPatchLayout::orig_cell). Cells with orig_cell outside [0, ibm->n_elmt) (ghost cells) are skipped for the copy-back into fem->act_data.
localIrePer-local-cell regular/irregular flag (from DMPlexPatchLayout::ire).
localValPer-local-cell valence (from DMPlexPatchLayout::val).
localPatchPer-local-cell 16-slot patch stencil, using original/global vertex indices (from DMPlexPatchLayout::patch).
use_reference_coordsPETSC_TRUE for geom0 (reference), PETSC_FALSE for geom (current).

Partitioned variant of RunCudaMetricTensorKernel for the DMPlex+CUDA path: operates on a per-rank local cell subset instead of the whole, undistributed ibm->n_elmt.

Reads fem->act_data.elem_act_data[ec].geom/geom0 (already computed, e.g. by RunCudaSubdivGeomKernelPartitioned) and writes g/g0/gm/gm0 back into the same elem_act_data entries.

Parameters
femFE struct (fem->ibm, fem->act_data, and each local cell's geom/geom0 must already be populated).
nLocalCellsNumber of cells owned by this rank's layout.
localOrigCelllocalOrigCell[lc] = original/global element index for local cell lc (from DMPlexPatchLayout::orig_cell).
